# Fairytale Hero System

Система выбора сказочного героя по его характеристикам.  
Проект создан в учебных целях и демонстрирует работу с FastAPI, PostgreSQL, SQLAlchemy 2.0+ и асинхронным стеком.

## 🚀 Возможности

- Добавление героев с характеристиками
- Поиск подходящего героя по фильтрам
- Асинхронная работа с базой данных
- Автоматическая нормализация характеристик (например: "злая" → "злой")
- Простая интеграция со статическим фронтендом

## 📁 Статический фронтенд

Папка `static/` содержит UI, **сгенерированный нейросетью**.  
Чтобы GitHub корректно определял основной язык проекта как Python, в `.gitattributes` добавлено:

```
static/** linguist-generated
```

## 🛠 Требования

- Python 3.12+
- uv (используется как менеджер окружения и зависимостей)
- PostgreSQL

## 📦 Установка зависимостей

Проект использует **uv**, поэтому установка выполняется так:

```bash
uv sync
```

Это создаст виртуальное окружение и установит все зависимости из `pyproject.toml`.

## 🗄 Настройка базы данных

Перед запуском необходимо указать строку подключения:

Создайте файл `.env` или используйте переменные окружения:

```
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/heroes
```

## 🧬 Инициализация базы данных


```bash
uv run python -m app.db.init_models
```


## 🌱 Заполнение базы тестовыми героями

```bash
uv run python -m app.db.seed
```

## ▶️ Запуск сервера

Проект запускается через uv:

```bash
uv run uvicorn app.main:app --reload
```

После запуска документация будет доступна по адресу:

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
